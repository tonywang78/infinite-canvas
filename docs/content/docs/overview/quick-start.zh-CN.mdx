# 快速开始

如果你只是想先把项目跑起来，优先部署或启动 `web/` 前端。

## Vercel 部署

在 Vercel 中导入仓库即可，根目录 `vercel.json` 会构建 `web/`。生成能力走平台积分接口，需要同时部署平台 API，并在管理后台配置渠道密钥与价目。

## 本地启动

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas
cd web
bun install
bun run dev
```

启动后访问：

```text
http://localhost:3000
```

## Docker 启动

如果你需要基于当前源码构建镜像：

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 infinite-canvas
```

## 首次使用建议

- 注册或登录后即可按积分生成；模型在账户中心选择平台 offer。
- 上游 API Key、渠道和价目只在管理后台配置，产品界面不会出现渠道密钥或调用脚本。
- 提示词库由平台同步后在 `/prompts` 浏览。

## 说明

- 当前画布项目和“我的素材”主要保存在浏览器本地，暂不提供云同步。
- 生成走平台积分接口，上游密钥只存在管理后台。
