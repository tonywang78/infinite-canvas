# Quick Start

To try the project, deploy or start the `web/` frontend.

## Deploy with Vercel

Import the repository into Vercel. The root `vercel.json` builds `web/`. Generation uses the platform credit APIs, so deploy the platform API as well and configure channel keys and prices in admin.

## Run locally

```bash
git clone git@github.com:basketikun/infinite-canvas.git
cd infinite-canvas/web
bun install
bun run dev
```

Open `http://localhost:3000`.

## Run with Docker

```bash
docker build -t infinite-canvas .
docker run --rm -p 3000:3000 infinite-canvas
```

## First-time setup

- Sign in to generate with credits; choose platform offers in Account.
- Upstream API keys, channels, and prices are configured only in admin. The product UI has no channel keys or call scripts.
- After an admin sync, browse prompts at `/prompts`.

Canvas projects and My Assets are primarily stored in the browser. Generation goes through platform credit APIs; upstream keys stay in admin.
