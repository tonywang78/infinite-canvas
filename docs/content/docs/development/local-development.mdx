# Local Development

The product runs `web/` with the platform API and admin. Generation uses platform credit APIs; upstream keys are configured only in admin.

## Start the frontend

```bash
cd web
bun install
bun run dev
```

Open `http://localhost:3000`. Start Postgres, `server/`, and `admin/` as well (see the root README). After an admin configures channel keys and prices, sign in on the frontend to generate with credits.

## Start the documentation site

```bash
cd docs
bun run dev
```

Common locations:

- Canvas, pages, and interactions: `web/`
- Prompt caching: `web/src/services/api/prompts.ts`
- Documentation content: `docs/content/docs/`
