# 本地开发

当前产品以前台 `web/`、平台 API 和管理后台一起运行。生成走平台积分接口，上游密钥只在管理后台配置。

## 1. 启动前端

```bash
cd web
bun install
bun run dev
```

前端默认访问：

```text
http://localhost:3000
```

## 2. 启动平台并登录

先启动 Postgres、`server/` 和 `admin/`（见根目录 README）。在管理后台配置渠道密钥与价目后，用前台账号登录即可按积分生成；默认模型在账户中心选择。

## 3. 启动文档站

如果需要单独调整文档站，在 `docs` 目录执行：

```bash
bun run dev
```

## 常见场景

- 改画布、页面和交互：主要看 `web/`
- 改提示词缓存：主要看 `web/src/services/api/prompts.ts`
- 改文档站内容：主要看 `docs/content/docs/`
